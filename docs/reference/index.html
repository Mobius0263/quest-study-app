Quest Study - Duolingo style mock

Reference export from the Quest Study UI Styles comparison page, Duolingo view only. This is a visual reference, not production React code - rebuild it as React components that call the planned REST API. The Quest Board filters work, quest cards open the Quest Detail, and completing the quest there shows the reward pop and unlocks the boss. The Quest Detail quiz step is playable (5 questions, pass 4 of 5, no timer) and the Boss Fight is a playable exam: 20 randomised questions, a 1-hour timer, boss and player HP, streak bonuses and win/lose states with at most 2 retries.

Sample data is the comparison page's shared sample content (Level 7, 1,240 / 1,400 XP, 12-day streak, daily goal 3 of 4, boss quiz: Limit & Turunan). The Quest Board and Quest Detail use the same sample quests, extended with a status, a description and steps so the regular quest flow can be shown end to end. See tokens.css / tokens.json for the exact design tokens, boss-golem.svg for the boss sprite, and icons.svg for the icon set.
